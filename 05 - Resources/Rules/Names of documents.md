# The Naming Rule for Reference Notes

Use a simple prefix to instantly identify the file as an external source, followed by the format, the author, and the title.

**Format:** `REF - [Type] - [Author/Creator] - [Title]`

**Examples:**

- `REF - PDF - Sommerville - Software Engineering 10th Ed.md`
    
- `REF - Video - FreeCodeCamp - AWS Certified Cloud Practitioner.md`
    
- `REF - Book - Martin Fowler - Patterns of Enterprise Application Architecture.md`
    
- `REF - Web - AWS Docs - S3 Bucket Best Practices.md`
    

### Why this structure works:

1. **Visual Clarity:** When you are typing a link (`[[...`) or using the Quick Switcher (`Ctrl+O`), typing "REF" instantly filters out all your class notes and permanent ideas, leaving only your bibliography.
    
2. **Agnostic to Subjects:** A book on system architecture might be useful for DSI today, but also for a personal backend project tomorrow. By naming it by its actual title rather than the university subject, it remains a universal resource in your vault.
