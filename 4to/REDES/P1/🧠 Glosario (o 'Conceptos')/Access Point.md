Redes Inalámbricas y Control de Acceso

- **[[Access Point]]** (Punto de Acceso): Es el dispositivo de red encargado de convertir la señal proveniente de los cables a señales de radio, permitiendo así que los dispositivos inalámbricos (como celulares o tablets) ingresen y se conecten a la **Red LAN**.
- **SSID**: Es el nombre identificador de la red inalámbrica que se define al configurar el equipo.
- **White List** (Lista Blanca) y **Dirección MAC**:

>[!question] ¿Cómo evitar que los alumnos se conecten a la red Wi-Fi de profesores? Para resolver este problema, el profesor indicó que la medida de seguridad ideal es implementar una **White List**. Esta lista no utiliza direcciones IP, sino que se configura utilizando la **Dirección MAC** (el identificador físico y preestablecido del hardware de cada equipo) para autorizar la conexión exclusivamente a los dispositivos deseados.
